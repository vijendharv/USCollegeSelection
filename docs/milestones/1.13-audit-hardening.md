# Milestone 1.13 — Audit correctness and data hardening

**Status:** Complete

**Implementation pull request:** Pending

## Objective

Address the actionable findings from the independent code audit in one consolidated milestone while preserving exact-program evidence and transparent admissions categories.

## Delivered behavior

- Ranking and gap analysis share one resident-aware comparable-cost selector.
- Résumé evidence defaults to `needs_review`; only explicitly confirmed evidence can be scored.
- Broad `Engineering` and `Business` inputs are rejected with examples of specific majors.
- Field-of-study and IPEDS loaders validate CIP formatting and report rejected samples on material drift.
- Scorecard discovery chooses the newest dated official archive when multiple links match.
- CSV extraction has a two-gigabyte decompressed-size ceiling.
- Reports identify the pinned IPEDS vintage and warn when it materially trails Scorecard data.
- Completion volume uses a diminishing-return availability bonus.
- National ranks include normalized top-percent positions.
- Relaxed category thresholds are explicitly flagged.
- Classification text states that course rigor is contextual and currently unscored.

## Verification

- Targeted regression tests cover cost selection, review defaults, broad majors, archive discovery, CIP validation, ranks, and threshold flags.
- Static checks, type checking, and the complete automated suite pass.
- A real local DuckDB smoke test verifies report generation without network access.

## Deferred work

- Automatic discovery of future IPEDS completion releases.
- Redirect-domain restrictions if networking is later exposed to user-controlled URLs.
