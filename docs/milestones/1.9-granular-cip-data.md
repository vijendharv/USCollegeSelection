## Objective

Replace broad two-digit-only major evidence with a hybrid federal-data model: six-digit IPEDS CIP records confirm exact bachelor-program availability, four-digit College Scorecard field records provide the strongest available program outcome evidence, and two-digit institution shares remain a lower-confidence fallback.

- Added a pinned, documented IPEDS 2024 Completions download containing six-digit CIP and bachelor award counts.
- Stored program granularity, credential level, completions, institutional share, earnings, debt, source name, and dataset version.
- Added reviewed CIP6/CIP4/CIP2 mappings for supported intended majors.
- Confirmed availability with six-digit IPEDS data and ranked outcomes with four-digit Scorecard data.

## Design decisions

- Use CIP6 for availability because it identifies the exact instructional specialty.
- Use CIP4 Scorecard outcomes for ranking because Scorecard intentionally aggregates to reduce privacy suppression.
- Never interpret completion count alone as program quality; it is an availability and scale signal.
- Keep CIP2 only as a fallback and visibly lower its confidence.
- Filter IPEDS to first majors (`MAJORNUM=1`) and bachelor's award level (`AWLEVEL=5`).
- Filter Scorecard fields to bachelor's credential level (`CREDLEV=3`).
- Pin the IPEDS release year in code so refreshes are reproducible and updates receive review.

## How to use it

Rebuild the local database once after upgrading:

```bash
uv run python -m app refresh-data
```

Then run reports normally; no network access is used by `demo`:

```bash
uv run python -m app demo --profile /path/to/student.json
```

## Deferred

- Automated discovery of a newer IPEDS completion year; the reviewed release is pinned for reproducibility.
- Major-specific admission rates and capacity constraints.
- Six-digit earnings/debt, which College Scorecard intentionally does not publish broadly.
- Institution-specific research, clinical, club, and honors-program availability.
