# Milestone 1.6 — PDF and Excel exports

**Status:** Complete

**Completed:** 2026-07-01

**Pull request:** Pending

## Objective

Render a printable PDF and a formatted five-sheet Excel workbook from the exact same canonical `CollegeReport`. Publish generated files through the private session-storage boundary and verify that both formats agree with the report.

## Delivered

### One report, two renderers

`render_pdf` and `render_excel` accept only a `CollegeReport` and return bytes. They do not access DuckDB, fetch sources, or recalculate classification and gap values. `export_college_report` selects either or both formats and publishes the bytes using `SessionFileStore`.

### Five-sheet Excel workbook

The workbook contains:

1. **College List** — classifications, confidence, location, admissions, cost, outcomes, links, missing data, and warnings.
2. **Gap Analysis** — one row per student-school comparison with numeric gap, status, note, and source.
3. **Student Profile** — confirmed profile, GPA, optional SAT/ACT, coursework, and confirmed holistic themes.
4. **Application Tracker** — editable plan, deadline, status, fee, supplements, and notes.
5. **Sources & Methodology** — dataset and institution sources, dates, methodology version, explanation, and disclaimer.

Every sheet uses a native Excel table, filters, frozen headers, hidden gridlines, wrapped content, and bounded column widths. Dates, rates, and currency remain typed values with explicit number formats. Website and source cells are clickable. Tracker plan and status cells have list validation.

All externally derived strings beginning with `=`, `+`, `-`, or `@` are escaped before export so they cannot become spreadsheet formulas. Automated tests scan every workbook cell for unintended formulas and exercise a malicious hyperlink-formula string.

### Printable PDF

The PDF starts with generation time, methodology, dataset identity, category counts, and disclaimer. Each school receives a clearly separated section containing classification, confidence, academic and cost comparisons, strengths, gaps, missing data, warnings, suggested actions, and readable sources.

Tables use fixed print-safe widths and repeating headers. Explicit school page breaks, margins, ASCII punctuation, and numbered footers keep the output printable and avoid clipped interactive-only content.

### Storage boundary

`SessionFileStore.write_file` validates the filename, requires an existing session, writes through a temporary file, atomically replaces the destination, and applies owner-only `0600` permissions. Export rendering remains independent of local versus future hosted storage.

### Free dependencies

- `openpyxl` creates `.xlsx` files.
- ReportLab creates PDFs.
- `pypdf` verifies PDF text and page structure.

No paid rendering service or third-party document API is required.

## Design decisions

- Render only from `CollegeReport`; output formats never reinterpret source data.
- Return in-memory bytes so document generation is independent of storage infrastructure.
- Keep editable tracker fields blank rather than inventing deadlines, fees, or requirements.
- Escape untrusted spreadsheet text centrally before writing cells.
- Use a predictable five-sheet structure for users and automated inspection.
- Give each school a PDF section so long comparison content can flow without horizontal clipping.
- Keep all generation local and free.

## How to use it

```python
from app.exporting import export_college_report
from app.models import ExportFormat

result = export_college_report(
    report,
    session_file_store,
    session_id,
    {ExportFormat.PDF, ExportFormat.XLSX},
)
```
