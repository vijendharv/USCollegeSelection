# Milestone 1.12 — Adaptive category fit thresholds

**Status:** Complete

**Implementation pull request:** [#18](https://github.com/vijendharv/USCollegeSelection/pull/18)

## Objective

Return useful choice sets without weakening every recommendation category. Start from a strong student-fit threshold and relax only a sparse major/category group, with a visible floor and a complete audit trail.

## Delivered behavior

- Student JSON has `preferences.recommendation_settings` with adaptive or fixed mode.
- Defaults are an initial threshold of 80, a floor of 70, five desired options, and ten maximum main-table options.
- Every intended-major and admissions-category group adapts independently in one-point steps.
- Adaptation stops when five candidates qualify or the floor is reached.
- Only confirmed six-digit CIP program matches participate in threshold qualification.
- Qualified candidates retain program-strength-first ordering; excess candidates remain in the addendum.
- Canonical JSON records each group's initial, floor, and applied thresholds plus exact, qualified, selected, and addendum candidate counts.
- PDF and Excel recommendation tables show the applied threshold. Excel also includes an `Adaptive Thresholds` audit sheet.
- Fixed mode keeps the initial threshold unchanged for users who do not want adaptation.
